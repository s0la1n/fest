# Изображения для сайта

Разместите здесь изображения для сайта.

**Рекомендуемая структура:**
- `about/` — фото для страницы «О фестивале»
- `cosplay/` — фото косплееров
- `teams/` — логотипы команд
- `hero/` — баннеры и главные изображения

**Примеры использования:** `/images/about/festival.jpg`, `/images/cosplay/photo1.jpg`
